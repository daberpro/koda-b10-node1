# Materi pengenalan node js
materi ini berfokus pada pengenalan node js, seperti node itu merupakan runtime untuk menjalankan javascript yang dimana node js sendiri 
menggunakan v8 engine sebagai inti dari runtime nya, dan juga didalam materi ini berfokus pada pengenalan modul - modul bawaan node js 
seperti `node:fs` dan lainya, selain itu juga diterapkan eslint untuk linter yang merupakan materi pada tanggal 22 - 10 - 2026
